# Security

Use a **private repository** for exact recovery details.

Never commit:
- passwords
- API keys/tokens
- `.webui_secret_key`
- browser cookies
- SSH/private keys
- personal PDFs/certificates
- sensitive OCR outputs
- model weights/caches
- raw Open WebUI databases unless intentionally encrypted and privately stored

For a public portfolio repo, sanitize usernames, personal documents and machine-private paths.
