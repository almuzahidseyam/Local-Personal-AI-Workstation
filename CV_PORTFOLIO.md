# CV / Portfolio Wording

## Project title
**Local Personal AI Workstation & Intelligent Document Processing Pipeline**

## CV bullets
- Designed and implemented a Windows-based local AI workstation using Ollama, Open WebUI, Docling and local language/vision models.
- Built an intelligent PDF pipeline that routes digital, scanned and difficult documents through native extraction, RapidOCR and vision-language OCR.
- Implemented local OCR quality assessment using structural heuristics plus an LLM judge, with escalation to a higher-quality VLM for difficult documents.
- Configured local RAG/embedding infrastructure for private document search and question answering.
- Enabled GPU-accelerated PyTorch/CUDA workloads and relocated large AI/model caches to dedicated storage.
- Automated service startup, health checks, OCR routing, logging and recovery using Python and PowerShell.

## Skills
Local LLM deployment; Ollama; Open WebUI; RAG; embeddings; Document AI; OCR pipelines; Docling; RapidOCR; VLMs; Python; PowerShell; PyTorch/CUDA; Windows AI infrastructure; technical troubleshooting.

## Interview wording
Say you **deployed, integrated, benchmarked and automated** foundation models. Do not claim you trained them.
